# Gestor de Tareas (CRUD)

Proyecto de la asignatura Programación III. CRUD de tareas en HTML, CSS y JavaScript
(sin dependencias; los datos se guardan en `localStorage`).

## Ejecutar
Abrir `index.html` en el navegador.

## Flujo de trabajo (Git Flow)
Ramas permanentes: `main`, `dev`, `qa`.
Ramas de trabajo: `feature/list-tasks`, `feature/create-task`, `feature/validate-task-input`,
`feature/edit-task`, `feature/delete-task`.
Cada rama genera 3 Pull Requests: hacia `dev`, hacia `qa` y hacia `main`.
